**最重要的觀念**：生成式 AI 基本上就是「想辦法找到（或生出）一個 latent vector，再用生成器（decoder）把它變成圖、照片或文字」。Autoencoder 在圖像生成裡的地位，就像「預測下一個字」在語言模型裡的地位。Diffusion Model 的巧妙之處，是讓 latent 變成**純雜訊**——電腦很容易生出雜訊，只要訓練一個很會「去雜訊」的 decoder，每一份隨機雜訊就能對應一張漂亮的圖；再把文字的 embedding 融進去，就能用 prompt 控制要畫什麼。

## 01. Embeddings

### 1.1 當前所有的 AI 都只是一個呆萌型 AI 機器人（P4）

- 就是知道**輸入是什麼、輸出是長什麼樣子**的函數學習機 $f_\theta$。

💬 老師補充：
- 好消息：前面有一個「其實算是簡單」的作業——你要做一個自己的呆萌型 AI 機器人會做哪一個——很多同學在這裡拿到最低分，因為**大家都做太高級**，「看起來都一點都不呆萌」。
- 再強調一次：呆萌型 AI 機器人本身是很簡單的模型，現代的 AI 基本上都是。**不能把其他幫它做的事也一起包下去**；我們重視的就是它的**輸入跟輸出**。

### 1.2 有一種任務我們很喜歡，但不知怎麼做……（P5–P6）

- 我們想找輸入的**特徵代表向量**（embedding、latent vector）。
- 當然不只是圖像：人物、文字、數據、聲音……總之所有可能的輸入，都有可能要找特徵代表向量。

💬 老師補充：例如輸入一張八哥照片，輸出它的特徵代表向量——還不是要做分類，可能之後拿去分類，也可能做別的事。它跟之前講過的文字特徵代表向量一樣是**抽象**的：拿出那些數字，我們不知道可愛的 AI 到底在想什麼。

### 1.3 問題是訓練資料要怎麼找呢？（P7）

- 不知道什麼是「**適當的**」特徵代表向量！

💬 老師補充：說起來簡單、做起來有點困難——我們不知道這隻八哥的特徵代表向量「應該」是什麼，沒辦法準備訓練資料（而且可能需要上千張照片）。

### 1.4 一個常用方法是設計一個「代理任務」（P8）

- 輸入八哥照片 → 輸出土八哥／白尾八哥／家八哥。
- **一個容易找訓練資料、需要理解輸入才能做到的任務。**

💬 老師補充：像之前做的八哥辨識，訓練資料（相對）很好找——土八哥找一千張照片就有一千筆訓練資料，輸出就是 1、0、0。代理任務不是我們真正要的，我們真正要的是特徵代表向量。

### 1.5 神經網路是一層層「隱藏層」打造出來的（P9–P10）

- 一層一層的輸出，就變成下一層的輸入：第 1 層輸出 → 第 2 層輸出 → 第 3 層輸出 → 第 4 層輸出 → 最終答案。
- 之前說過，每一個隱藏層的輸出都可以當成 AI 對輸入的**理解**。模型最終準確度很高，表示理解得很正確，也就是**任何一個隱藏層的輸出，都可以當成 embedding**，也就是輸入的特徵代表向量。

💬 老師補充：
- 投影片簡化成四個隱藏層（應該要更多）。每一層吐出一堆數字（一個向量）傳到下一層，最後一層出現最熟悉的三個分數（土八哥、家八哥、白尾八哥）。
- 為什麼說它理解得很好？因為它真的靠這個理解得到正確答案。
- 每一層都可以，但常取**最後一層**或**第一層**。常取第一層的原因很簡單：以後要找特徵代表向量只要那一層就可以，馬上得到一個還不錯的向量。你可能覺得第一層幾乎沒在想、只做很粗淺的想法，照說後面的應該更好——「大家去想一想，取第一層有好處也有壞處」。

### 1.6 我們只用輸出到 embedding 層的神經網路（P11–P12）

- 這個輸出到 embedding 向量的模型，我們會叫 **encoder**。
- 當然不只圖像辨識：輸入（圖像、文字或其他任何數據）→ encoder → 輸入的特徵代表向量（latent vector、embedding）。

💬 老師補充：
- 訓練完代理任務後，把神經網路**截斷**到選定的那個隱藏層為止，輸入一張照片，輸出就是特徵代表向量——之前學過文字的 embedding，現在變成圖像的 embedding。
- 叫 encoder（編碼器），因為它把具體的照片或數據編成「神秘的編碼」，就是它神秘的理解方式。
- 今天學一個新詞 **latent vector**（潛向量、潛在向量）——「不要想了」，就是特徵代表向量的意思。

### 1.7 比如說 Word2Vec 的兩個小任務（P13–P15）

| 模型 | 任務 |
|---|---|
| CBOW model | 用周圍的字預測中間的字（$x_{t-2}, x_{t-1}, x_{t+1}, x_{t+2} \to x_t$） |
| Skip-Gram model | 用中間的字預測周圍的字（$x_t \to x_{t-2}, x_{t-1}, x_{t+1}, x_{t+2}$） |

- 某個隱藏層的輸出就是 embedding——我們可以找到字的 embedding！

💬 老師補充：代理任務有一個很重要的原則——**要足夠理解輸入，才能解決這個任務**。不需要理解就能做到的，當然不能當代理任務；預測中間的字或周圍的字，都需要某種程度理解文字的意思。

### 1.8 事實上前一個字預測下一個字也是！（P16）

- 輸入 $x_t$ 加上之前的「記憶」$h_{t-1}$，輸出 $h_t$、預測 $x_{t+1}$；$h_t$ 可以想成是一個 embedding。

💬 老師補充：大型語言模型要從前面一堆字預測下一個字，當然要懂文字的意思，所以**訓練過程本身就是很好的代理任務**。LLM 也有 embedding，但 encoder 不是先獨立訓練，而是**跟語言模型一起訓練**：第一個隱藏層叫 embedding 層，它的輸出就是 embedding。

### 1.9 生成式 AI 基本上就是這樣的模型（P17）

- $z$（latent vector，特徵代表向量）→ **生成器** → 生出圖、照片、文字。

💬 老師補充：不管要生成什麼，就是想盡辦法找到特徵代表向量；它代表某一個意涵。之後會討論很多：我有意圖想產生特定的畫面、聲音、文字時，到底怎麼把這個 latent vector 做出來。

## 02. 自編碼器 Autoencoder

### 2.1 Autoencoder（P19–P20）

- 生成圖像時，我們有一個常用找 latent vector 的方法，叫**自編碼器（Autoencoder）**。
- 這個代理任務聽來很奇怪……**輸入是什麼、輸出就是什麼**的模型。

💬 老師補充：
- 「大家看完了就會吐血」——它真的很呆很笨，完全符合呆萌型 AI 機器人該做的事。後面很少直接用它，但**很多概念都從它來**：語言模型裡最重要的概念是「預測下一個字」，圖像裡很重要的核心就是 Autoencoder。
- 它是**全世界最容易找訓練資料**的：輸入一張圖，正確答案就是完全一樣的圖。「這種模型簡直是白癡啊，輸入什麼就輸出什麼，要你學幹嘛？」——關鍵是我們要的不是這個模型，而是它中間某一個隱藏層的輸出。

### 2.2 訓練好我們同時得到 encoder 和 decoder（P21–P23）

- 原本的模型 = encoder → latent vector → decoder。
- **Encoder（Embedding）就這麼出現了！** 特徵向量就這麼找出來了——這個特徵代表向量就代表了這張圖的特徵。
- **同時生成器（decoder）也出現了！** 輸入 latent vector，就生出圖。

💬 老師補充：
- 從哪一層拆成 encoder 和 decoder 是我們自己決定的（「我們高興」）。通常 latent vector **比原來的圖小很多**——不然跟原圖一樣大到底在搞什麼？（「這句話我們等一下就會打自己了」）。也不一定是 vector，可能是矩陣、tensor，所以也叫 latent tensor。
- 要小成多少自己定：例如設計一個隱藏層有 128 個神經元，就用 128 個數字代表這張圖。
- 為什麼說它真的理解原圖？在那個點，**所有的資訊只有那 128 個數字**，它卻能一路走下去把圖還原出來——表示它掌握了原圖所有的精華和特徵。
- 但訓練成功只能生出原本給它的訓練資料，沒有創作新的作品。

### 2.3 可以生成沒有學過的圖嗎？（P24–P25）

- 改一點點我們的 latent vector，應該會生出很類似的圖……對吧？
- Latent vector 只是高維度空間的一個點，代表一張圖片，我們希望它附近的點應該也很像 $z$ 代表的圖片。

💬 老師補充：我們幻想稍微改一點，會是同一個人換了髮型、頭髮顏色不一樣、戴上眼鏡、衣服或手勢不一樣……做不到的話，這個模型不知道要幹嘛，因為它只能生成原來學過的圖。

### 2.4 答案是不太行（P26）

- 隨便生兩個 latent vectors，數學上距離很近，但生出來的東西不一定有什麼關係。
- 白話文是 **$z$ 差不多就是亂數，我們無以掌控。**

💬 老師補充：
- 與其說它抓到了很好的特徵代表向量，不如說它找到一個**非常巧妙的儲存方式**：把圖存到某個位置，記得這個位置的圖長這樣、那個位置長那樣，有點隨機地塞進去。所以只變一點點，產生的圖基本上沒什麼關聯，大部分時候甚至產生不了圖，出現很奇怪的東西——除非要做非常抽象的藝術創作。
- 問題在於太隨機：latent vector 裡每一個數字**沒有符合常態分佈**（它就是亂塞的）。最自然的想法：希望每個位置都符合常態分佈，這樣在合理範圍內就會生出類似的東西。

## 03. 變分自編碼器 VAE

### 3.1 改善自編碼器問題的 VAE（P28–P29）

- **VAE（Variational AutoEncoder）**
- 希望 latent vector 每個元素符合常態分佈：$z = (z_1, z_2, \dots, z_k)$，$z_1 \sim \mathcal{N}(\mu_1, \sigma_1^2)$……
- 我們想辦法找每個數的平均值和變異數（或標準差）。
- 神秘編碼 latent vector 每個數字是符合某常態分佈的，這樣我們容易掌控！

💬 老師補充：名字看起來非常有學問，叫「變分自編碼器」。Autoencoder 有點像把圖硬背下來，背的方式很巧妙、我們不知道怎麼背的；VAE 就是**強迫每一個位置都要符合常態分佈**。我們很喜歡用 $z$ 表示 latent vector。「這聽起來很酷炫很了不起，其實後來大家就知道，我們在很多地方其實都是騙人的。」

### 3.2 其實就是要函數學習機去學平均值和標準差！（P30）

- 輸入 → 輸出 latent vector 前的模型 → $\mu_1, \mu_2, \mu_3$ 與 $\sigma_1, \sigma_2, \sigma_3$ → 用平均值和標準差生出 latent vector $z_1, z_2, z_3$。

💬 老師補充：
- 要怎麼強迫它符合常態分佈？非常簡單：latent vector 有 3 個數字的話，**前一層就有 6 個數字**——前 3 個學每個位置的平均值，後 3 個學標準差。$z_1$ 就從 $\mu_1$、$\sigma_1$ 的常態分佈抽樣出來，$z_2$、$z_3$ 同理。
- 有趣的是：**即使是同一張圖、同一個網路，走到 $z$ 的時候每次都會有一點點不一樣**，因為是抽樣出來的。
- 這樣訓練後，動一點點真的會變成有一點點變化的東西，例如兔子變成不同毛色的兔子——「它真的會有一點點創作的能力」。
- （插曲：老師把 $z_1, z_2, z_3$ 念成「G1、G2、G3」，順便講了個笑話：在台灣按電梯都念 B1、B2，到 B3 一定念「逼三」，證明自己是台灣人。）

### 3.3 Deepfake 可以這樣做出來（P31–P32）

- 用 autoencoder 就可以做到 deepfake：A 有自己的 encoder A／decoder A，B 有 encoder B／decoder B。
- 用 **encoder A** 做出的 latent vector，送進 **decoder B** 之中。

💬 老師補充：
- 這是 **Deepfake 的第一版**，現在已經不是這樣做了，「所以可以很大膽、放心地交給大家」。
- 收集某人 A 的很多影片，訓練 A 的 encoder 和 decoder；B 也訓練一組。要把 A 換成 B：用 A 的 encoder 抓到這個人現在的動作等各種特徵，還原時用 B 的 decoder——它只會還原 B 這個人，所以就換過去了。
- 現在覺得要訓練兩個神經網路太複雜，已經不這樣做；這裡只是說明 VAE 某種程度達成了我們的效果。

### 3.4 後話說在前面（P33）

- 大家覺得 autoencoder 好像變化有點少，品質也不是太好，生成模型一度 **GAN 獨大**，不過後來世界又變了……

💬 老師補充：VAE 動一點點不會動太多，創作不會天馬行空；特別是訓練資料不多時，創作會侷限在學過的那幾個樣子。（現在說的 Autoencoder 其實都是 VAE。）所以大家一度覺得 GAN 會是圖像生成 AI 的統治者——但不久之後世界變了，Autoencoder 又再度回來扮演某種角色。

## 04. 橫空出世的 Diffusion Models

### 4.1 Text to Image Models（P35）

- "a rabbit wearing a rabbit ear hat" → $f_\theta$ → 一隻戴著兔耳帽的兔子照片。

💬 老師補充：之前閃電秀有同學做影片生成，就知道是用 Diffusion Model（現在也不一定，但很多時候是）。這張兔子圖「相當早期」——其實也才三、四年前，在 AI 的時代，四年前就算相當早以前了。

### 4.2 幾個現在還有的 diffusion models（P36）

| 模型 | 說明 |
|---|---|
| Qwen Image 2.1 | 開源 |
| Flux.2 Pro | 開源 |
| Z-Image-turbo | 開源 |
| Midjourney | 閉源的線上服務 |

💬 老師補充：
- 左邊三個是**開源模型**，很適合在自己電腦上、用 NVIDIA（「已經不是黃仁勳的 NVIDIA，是那家公司」）的 GPU 跑。
- **Midjourney** 是一開始生圖時就非常有名的線上服務，**閉源**——像生圖界的 ChatGPT，沒有公開模型長什麼樣子。
- 四張圖用同樣的 prompt（老師記得大概是一隻貓用吸管喝 Starbucks 咖啡）。
- 好消息：一開始只能用英文下 prompt（「練英文非常好的機會」），現在幾乎全部可以用中文。比較合理的使用情境：想在自己電腦裝一個「愛生什麼就生什麼」的模型，就比較有機會用到這些 Diffusion Model。

### 4.3 各種風格的 prompt（P37–P41）

| 風格 | prompt |
|---|---|
| Whimsical Watercolor Illustration | whimsical watercolor illustration，一個在施展魔法的可愛小女巫 |
| Claymation | claymation，一隻可愛的熊貓，戴著眼鏡，在沙發上用著他的 MacBook 筆電 |
| 3D Pixar 卡通風格 | 3D animation, Pixar 卡通風格，超可愛的機器人，拿著水彩筆和調色盤，在畫一幅水彩畫 |
| Simple 2D Vector Art | simple 2D vector art, minimalist, very few details, pastel colors，一個可愛的女孩在咖啡店中用她的筆電 |
| 一點也不像的 David Shrigley 風格 | A white llama holding a laptop… drawn as a David Shrigley style illustration, using only black lines on a clean sky blue background…（較長的英文描述） |

💬 老師補充：
- 你會去蒐集很多**風格**關鍵詞：黏土動畫（claymation，每一個都看起來像黏土人）、Pixar 3D 卡通、吉卜力風格……也可以很仔細地描述你要什麼風格。
- 差距就在**你的藝術涵養和描述圖像的能力**——比較會生圖的「當然絕對不會是對 AI 技術很熟或寫程式很厲害的人」，而是比較知道怎麼描述一張圖的人。
- P41：告訴它想用某個人的風格，它不一定真的弄出那個風格，只是用某個風格給你看，大家可以多嘗試。

## 05. Diffusion Models 原理

### 5.1 當然說「橫空出世」也不太對……（P43–P44）

- 2015 年就有了！Sohl-Dickstein et al., "Deep Unsupervised Learning using Nonequilibrium Thermodynamics," 2015. <https://arxiv.org/abs/1503.03585>
- 但關鍵是這篇：Dhariwal & Nichol, "**Diffusion Models Beat GANs on Image Synthesis**," 2021. <https://arxiv.org/abs/2105.05233>——OpenAI 這篇說 Diffusion Models 在圖像生成可以擊敗 GAN！

💬 老師補充：
- 老師認為 Diffusion Model 比 ChatGPT 那類更「橫空出世」：ChatGPT 的概念 2015 年就長那樣，令人驚奇的是這麼簡單的概念能達到這種效果。
- Diffusion Model 2015 年就有了，只是沒引起重視：計算量非常大、當時 GPU 也沒那麼厲害，大家覺得還是用 GAN 生圖比較對。
- 2021 年 OpenAI 的文章讓大家發現它在合理的計算下真的能生出圖。大約 2022 年、跟 ChatGPT 出來差不多同時（「也只有四年前，大家都出生了」），大家開始討論用 AI 生圖，那時是 Diffusion Model 最強盛的時候。

### 5.2 大家還記得 Autoencoder 嗎？（P45–P47）

- 那個輸入和輸出都一樣的超呆機器人……
- **GPT 唬爛王給我們的啟發**：也許看得夠多，唬爛——我是說「創作」的能力就會強！
- **Diffusion Models 基本上就是 Autoencoder!!** 只差前面 encoder 是**算出來的**!!（encoder：這是算出來的；decoder：這裡是神經網路）

💬 老師補充：
- 2015 年 Karpathy 寫那篇有名的部落格文章時，就知道「前面的字預測下一個字」怎麼做，只是不知道能那麼厲害；後來 GPT-2 加強訓練、模型變大，ChatGPT 用海量資料訓練。
- 所以大家想：說不定看起來呆呆的 VAE、Autoencoder 也能變得很厲害——**Diffusion Model 的基本想法就是在做 Autoencoder，只是用了海量資料去訓練**，訓練完突然發現它什麼都會畫了。
- 跟一般 Autoencoder 不同：encoder 沒有訓練，是算出來的，**唯一要訓練的是 decoder**。

### 5.3 Diffusion：一步步加上高斯雜訊（P48–P50）

- 用相同的計算方式，一步步加上高斯雜訊：$x_0 \to x_{50} \to x_{100} \to x_{150}$。
- 就是一路加上雜訊：

$$x_t = \sqrt{\alpha_t}\, x_{t-1} + \sqrt{1-\alpha_t}\, \varepsilon_{t-1}$$

- $\beta_t$ 我們就是取個很小的數字，而 $\alpha_t = 1 - \beta_t$；一般我們會取 $\beta_1 < \beta_2 < \cdots < \beta_T$。
- 一次擴散一點點：為什麼要做這樣的事呢？因為每一個點就會是一個常態分佈抽樣出來的，我們很容易生出這樣的 latent tensor，然後應該會對應一張圖！

💬 老師補充：
- 從一隻小彎嘴畫眉（$x_0$）開始，每一步**只加一點點**雜訊，加到看不出是什麼——像以前電視訊號不好時的雜訊畫面。$x_{150}$ 可能不夠，可能要加到 **1000 次**左右。
- 希望最後每一個點都是真正的雜訊：符合某個常態分佈（通常是**標準常態分佈**）。直接從標準常態分佈抽樣，通常很難直接看起來像照片；但**最右邊那張電腦很容易生成**（要抽幾個數字就抽出來），最左邊那張要生成，就等於直接把圖生出來了。所以最右邊就是我們的 latent vector，很容易做出來——**這是重點**。
- 中間的 $x_{50}$ 還隱約看得到鳥，$x_{100}$ 很不明顯但 AI 說不定看得出來，$x_{150}$ 完完全全是雜訊。創作時每次生出一份符合常態分佈的雜訊，就應該對應一張漂亮的圖。
- 為什麼叫「擴散」：像在密閉空間噴精油，味道慢慢擴散得很平均；目標是擴散到平均穩定時停止（P50 的螺旋圖就是這樣慢慢擴散）。
- **為什麼每次只能加一點點？** 從第二張圖預測第一張應該容易；從最右邊猜它本來在畫什麼就很難。

### 5.4 一個小技巧：一次到位（P51–P52）

- 事實上我們不用 $x_0, x_1, x_2, \dots$ 這樣算下去，可以一次到位！令

$$\bar{\alpha}_t = \prod_{i=1}^{t} \alpha_i$$

$$x_t = \sqrt{\bar{\alpha}_t}\, x_0 + \sqrt{1-\bar{\alpha}_t}\, \varepsilon$$

- **也就是 encoder 我們不用學！** $x_0 \to x_T$ 是算出來的（當然有從常態分佈抽樣的部份）。

💬 老師補充：這只是公式整理，不仔細解釋。意思是一般可能要加約一千次雜訊，但**不用真的算一千次**，有公式可以從最左邊的鳥照片直接算到最右邊——「這是很令人開心的事情」。一開始大家常取 $T = 1000$ 步。

### 5.5 然後我們就用神經網路，訓練一個 decoder（P53–P56）

- $x_T$ → decoder → $x_0$。
- 你可能會問：encoder 是用算的，為什麼 decoder 不能算回來呢？
- 整個過程其實就像迴歸一般（散點 → 一條曲線）；只是難度更高：**更亂，而且我們也不知道目標是什麼形式的函數**。

💬 老師補充：
- 硬從完全像雜訊的東西直接輸出鳥照片——「你自己覺得合理還是不合理？」大家應該都覺得不太合理（也可以好奇硬去訓練看看）。
- 為什麼 decoder 不能算回來？encoder 一步步加的雜訊有隨機成分，是**我們決定怎麼加的**，所以算得出來；decoder 不知道它到底加了什麼。
- 像迴歸：看到一堆點很像某條線，就可以做迴歸——但迴歸要知道基本形式是直線還是某種曲線；像雜訊那麼混亂，連目標應該是什麼形式的函數都不知道，就沒辦法做迴歸。

### 5.6 理論上這還原的動作應該也是一步步來（P57）

- $x_t$ → decoder → $x_{t-1}$。

💬 老師補充：一步一步訓練：從 $x_{1000}$ 推出 $x_{999}$，再放進去推 $x_{998}$……理論上算 1000 次（「大家不用緊張，不會真的算 1000 次」），就知道原圖長什麼樣子。

### 5.7 好消息是只學 noise 的部份比較容易（P58–P61）

- $x_N$ → decoder → noise $\varepsilon$。
- 訓練成功我們圖就可以生出來了！$x_N - \varepsilon = x_0$
- 於是我們就可以生圖了！隨機生出 $z$ → $\varepsilon_\theta$ 預測 $\varepsilon$ → $z - \varepsilon$ ＝ 一張圖。
- 其實可能會重覆去雜訊的工作。

💬 老師補充：
- 直接學 $x_{t-1}$、甚至 $x_0$ 比較難；**只學「從一開始到現在被加了多少 noise」相對簡單**，所以後來的神經網路是訓練去預測雜訊。
- 訓練資料也這樣準備：雜訊都是我們自己加上去的，當然知道加了多少。知道加了多少，把雜訊減掉就找回原圖。

### 💬 5.8 排程器（scheduler）與在家用 Diffusion Model（影片約 0:50 起）

- 一個細節（上次開課時還是重要的細節）：最牢靠的方法是每次推一步、不要跳太多步；但加了一千步雜訊，去雜訊就要一千步才生出一張圖，「大家會等著瘋掉」。
- 所以很多人研究怎麼用比較少的步數達到目標——這叫**排程**，用的是**排程器（scheduler）**。
- 有機會用開源模型時，會看到它推薦用哪個排程器、要用幾步完成。步數少不一定比較快：有些步數很少，但每一步的計算量很大。
- 老師很誠實：課程基本上不會特別再用 Diffusion Model，不用太擔心。但它**目前還是最適合在自己家裡電腦（有 GPU）生圖**的模型（後面會介紹現在大家生圖是怎麼生的、不是用 Diffusion 的方法）；GPU 還不錯、想在家生影片、不想訂閱外面一直讓你有「token 焦慮」的付費服務，用的還是 Diffusion Model。

## 06. Latent Diffusion Models

### 💬 6.1 為什麼需要 Latent 版？（影片約 0:54 起）

- 一般 Autoencoder 的 latent 比原圖小，但 **Diffusion Model 每一步的 latent tensor 跟原圖一模一樣大**——這就是剛剛說「會打自己」的例外。
- 右邊（decoder）才是真正的神經網路，是 **U-Net**（處理圖像很厲害的 CNN），後來也有人用 Transformer。
- latent 完全沒縮小，所以訓練非常耗資源。2015 年出來時看不到具體成效、訓練很耗資源、計算很慢……種種缺點讓它一直沒大紅。
- 後來大家想到 **LDM（Latent Diffusion Model）**——「出去外面要騙人的詞又來了」：latent 就是剛剛潛向量的 latent。簡單說就是**先把圖壓到比較小，再拿去做 Diffusion Model**。

### 6.2 Stable Diffusion（P63–P65）

- Rombach et al., "High-Resolution Image Synthesis with Latent Diffusion Models," 2022. <https://arxiv.org/abs/2112.10752>——**這就是 Stable Diffusion！**
- 先訓練個前面說的 VAE：encoder → $z$ → decoder。
- 標準 Stable Diffusion 是縮小八倍：512 × 512 → 64 × 64 → 512 × 512。
- **真正用 diffusion model 的是中間 latent vector。**

💬 老師補充：
- 老師猜現在當紅的 Diffusion Model 基本上都是 Latent Diffusion Model。
- 先照正常 VAE 的方式訓練（encoder、decoder 兩邊都要訓練）。其實原圖是 512×512×3，latent 是 64×64×4，「這個我們不管，總之 latent tensor 比原圖小」。
- 那張 64×64 的「圖」人看起來已經像亂碼、像雜訊，只有 AI 的世界懂。做 Diffusion 時就把這些 latent tensor 當成圖，在「它詭異的生圖世界」裡每張圖只有 64×64，加雜訊、學去雜訊；生出來的圖我們看不懂，要再用 VAE 的 **decoder** 才看得到原來的圖。

### 6.3 這種先用 VAE 的模型叫 LDM（P66–P67）

- 所以不要再說外行話，什麼「用 VAE 改善我們的輸出品質」——**沒有 VAE，Stable Diffusion 根本不能動！**
- 但我們可以不用原本預設的 VAE：Stable Diffusion 提供三個版本的 VAE（預設、EMA、MSE）。

💬 老師補充：以前常有人說「我用某個 VAE 表現比較好」，其實沒有 VAE 不可能用 LDM，它一定有 VAE；只是會訓練不同版本的 VAE，同一個 latent tensor 放進不同 VAE，還原出來的圖有些比較好、有些比較差。一開始有不同 VAE 可以選，但我們其實不用管它。

### 6.4 那文字生圖是怎麼做到的呢？（P68–P70）

- 一般就是用很會處理文字的 transformer model，把 prompt 化為特徵代表 tensor $y$（想成一堆數字或向量就好）。
- 然後「加到」我們隨機生成的那些 noise：$z = z_T + y$（$z_T$ 是隨機生出的，$y$ 是代表文字意思的）。
- 是不是和 StyleGAN 很像？這裡「加」也不一定是真的加……
- 標準「融合」通常是用 transformer：**$K$、$V$ 是文字這邊來的，$Q$ 是隨機生出原始 latent vector 來的**。

💬 老師補充：
- 剛剛的模型還缺一件很重要的事：latent tensor 很容易產生（標準常態分佈，平均值 0、標準差 1），看過真的很多圖的話，每一個隨機抽樣都應該對應一張漂亮的圖——但**沒有把文字放進去**，沒辦法控制「我要畫一隻可愛的大橘貓，坐在客家飯店裡面喝咖啡」。
- 做法：訓練某種語言模型，輸入文字、輸出 embedding（「今天到處都充滿 embedding」），再想辦法把語意融進隨機生成的 latent tensor，變成最終的 latent tensor。
- 「這語意你高興怎麼加都可以，只要聽起來蠻有道理的就可以」——這就是為什麼學 AI 要知道原理。因為我們會 Transformer：QKV 的計算某種程度就像把語意混進去。（「其實不可以沒關係，總而言之就是想辦法把語意融進去就對了。」）

### 6.5 Stable Diffusion 架構圖（P71）

```text
prompt ──→ CLIP ──→ 文字 embedding（77 × 768）
                              │
隨機產生雜訊 ~N(0,1) ──→ latent 張量（64 × 64）──→ U-Net 雜訊預測 ──→ 預測雜訊（64 × 64）
                              ↑                                        │
                              └──────── Scheduler（重覆 N 次）←────────┘
                                                                       ↓
                                                     VAE decoder ──→ 生成圖（512 × 512）
```

💬 老師補充：
- 文字模型 **CLIP** 產生 77×768 的 embedding——「為什麼？這沒有為什麼，就高興」。
- decoder 是 **U-Net**，特徵是**輸入多大、輸出就多大**；依 scheduler 重複想要的次數，最後送進 VAE 的 decoder 生成看得懂的圖。訓練只在左邊，右邊的 VAE 是已經訓練好的。
- 這張架構圖雖然以 Stable Diffusion 為例，但 Diffusion Model 基本上就長這樣——**知道得很清楚，就完全理解 Diffusion Model 怎麼運作**。

### 💬 6.6 U-Net 與 CLIP 補充（影片約 1:08 起）

**U-Net**
- 名稱由來：一開始隱藏層跟原圖一樣大，慢慢縮小、縮小，還原時再放大、放大到原圖大小才輸出，整個神經網路畫出來像 **U 字形**。它是 CNN。
- 八哥辨識不需要輸出跟輸入一樣大（CNN 的特徵圖因為 max pooling 越來越小，只是數量越來越多）。早期研究 U-Net 時，大部分情境都覺得「為什麼要輸入跟輸出一樣大？」不太合理。
- U-Net 以前很適合做 **segmentation（分割）**：把圖中的人物、物品框起來塗滿顏色，輸出跟輸入一樣大，才能精確學到該標在哪裡。Diffusion Model 剛好要輸入輸出一樣大，天生適合 U-Net。
- 出去吹牛（例如面試時）講「U-Net 輸入跟輸出一樣大、CNN 隱藏層越來越小再放大、形狀像 U」，老闆會覺得你超懂——「其實你也沒有真的懂，只是記得老師說的話」。

**CLIP**
- 說它是文字模型也沒錯，但訓練方式很有趣：上網搜尋圖片和它的**圖說**（解釋這張圖是什麼）。
- 基本想法：一張圖用圖像呈現，用文字描述它，代表的意義應該一樣，只是呈現方式不同。所以文字經 CLIP 的 embedding，跟那張圖的 embedding（可能是另一個模型）**要很接近**。
- 用的是之前介紹過的**對比學習（contrastive learning）**：同類拉近、不同推遠——只是拉近的一個是圖的 embedding，一個是文字的 embedding。
- 使用時只用它文字 embedding 的部分，但它的特色就是文字 embedding 會跟它代表的圖像 embedding 很接近。
- 有些地方講得比較快，因為不想花太多時間在 Diffusion Model；但影片生成、開源模型很多還是用它，而且 **VAE 之後還會在很多情境出現**，所以還是要好好介紹。

### 6.7 解碼（生成）最主要是用 U-Net（P72）

- 我們的「想法」（prompt）至少有兩個參數可以調整：**Stop At = 0.5**、**Weight = 0.6**。

💬 老師補充：
- prompt 什麼時候融進 latent tensor？**U-Net 的每一個隱藏層都會融進去一次**，甚至融到最後面。
- 生圖技巧：開始時限制要畫這樣的圖，後面希望它天馬行空一點。有些模型「可能是訓練太好」，同一個 prompt 讓它多畫幾張，會發現那幾張圖很像。兩種基本參數：
  1. **Stop At**：prompt（例如「畫一隻貓」）告訴它到什麼地方就停，後面讓它更天馬行空地創作。
  2. **Weight（權重）**：要不要那麼強調照我的意思畫，要不要「死盯著」我的意思。
- 想在自己電腦（甚至斷網時）生圖、生影片——「我現在想也覺得蠻酷的」（影片需要更高階的 GPU）——現在最好的選擇還是 Diffusion Model，會有上述調整、VAE 和排程器的選擇；不過大部分模型都已經推薦好該用的 VAE、排程器和參數值，想要更多創作再去調。
- 真的想用（特別是以後考慮用電腦生影片），現在大多用 **ComfyUI**，Mac、Windows 都有，可以看別人用什麼模型生圖、生影片。先從生圖開始——「如果你覺得生圖已經了無生趣了，千千萬萬不要再去生影片，會更了無生趣」。
- 本來想用這個當作業，但那樣每一家都要新買一台很貴的電腦，有點過分，所以不出這樣的作業。

## 💬 助教時間：AI 角色互動設計（影片約 1:37 起）

### 宣布事項

- 這週沒有閃電秀，仍非常鼓勵大家報名，分享最近在 AI 實作上看到的有趣現象或嘗試。

### 為什麼談角色互動設計？

- 大家開始準備期末專案，很多人想做能生成**特殊性格回答**的聊天機器人；作業和閃電秀也看到很多 AI 角色扮演聊天機器人。今天結合第 2、6、7、8 週的內容來談。

### System Prompt 的優化（回顧第六週）

第六週學過：設計 System Prompt＋串接大型語言模型，做出自己的 AI 聊天機器人；System Prompt 很大程度影響最後的回覆。助教用自己做的聊天機器人回覆，反推 System Prompt 可以怎麼設計：

| 設計項目 | 例子 |
|---|---|
| 抽象性格詞彙 | 霸道、強勢、聰明……（霸道總裁、《甄嬛傳》的甄嬛）——大家都很會 |
| 規則 | 每次回覆不要加 emoji、要什麼格式產出 |
| 喜好、職業 | 律師、總裁、皇后……；例：很活潑開朗的小朋友，常用 emoji，喜歡脆皮炸雞翅 |
| emoji 與顏文字 | 讓回覆更活潑、具象化，像在 LINE 上跟人聊天 |
| 角色扮演式對話格式 | 像劇本、小說：角色不只有對話，還有動作和表情 |
| 背景資料 | 憂鬱的角色小時候經歷過什麼、孤苦伶仃；霸道總裁的家庭背景、名校畢業——讓性格表現更有因果關係，更活靈活現 |

- 大家常把 System Prompt 丟給 AI 優化（「活潑」→「活潑開朗、很愛笑」）。
- **對話格式範例**：「對話」用引號括住（像看小說），後面用括號寫動作、表情。多角色的（期末提案有人想做 TRPG 之類較龐大的聊天系統）：前面先寫角色名字，再寫對話、動作和表情；也可以先寫動作再寫話語。

### Vibe Coding 讓介面更有趣

- 一般聊天機器人介面黑白、充斥文字、簡約單調（沒有不好），但可以用 Vibe Coding 工具（如 Antigravity）讓介面更有趣：手帳風、各種顏色和層次、特殊的排版風格；也可以融入角色素材，做出更好的角色互動體驗。

### 角色素材的提示詞

| 素材 | 做法與用途 |
|---|---|
| **角色卡（Character Sheet）** | 做其他角色素材前先生一張當參考圖，維持角色一致性：全身像＋三視圖（前、左、後、右）。可裁下最左邊的全身像當聊天介面背景（比較適合 9:16 介面） |
| 1:1 Q 版、像素風 | 以 Character Sheet 當參考圖，提示詞寫角色視覺特徵＋「Pixel Game Style」或 chibi（Q 版）；再用網路去背工具去背（白底有時也不太影響，總比只有文字好） |
| **RPG Action Sheet／Character Sprite Sheet** | 動作表：去背、剪輯拆成一格一格。例：做 **AI 桌寵**，從桌面左邊走到右邊，用動作表的影格就比單一圖像生硬地滑過去活靈活現（像《電馭叛客：邊緣行者》裡的東西） |
| **Emoji Package** | 生成 16:9、含 8 個表情的圖（之前就有人用 AI 做 LINE 貼圖）。用 Python 判斷 AI 回覆的情緒（開心、悲傷、哭、生氣、驚喜……），顯示對應表情圖，像在跟有表情的角色聊天 |
| 半身像 | 霸道總裁類聊天機器人很好用（提示詞已放在 NTU COOL），插入網頁式聊天機器人，可搭配 GitHub Pages |
| 動態影片／GIF | 靜態圖變成影片或 GIF：開心時循環播放一段、焦慮或肚子餓時播另一段；聊天時背景一直播放，像真的在跟 AI 角色互動（例如你的員工在旁邊工作） |

**生成工具示範**
- 學生方案可用 Google 的生圖／生影片平台（逐字稿聽不清楚名稱）；沒有學生方案每天也有免費點數——助教用免費版 50 點就生了一大堆素材（是在老師的 AI 工作坊學到的）。
- 步驟：新建專案 → 選「角色」→ 輸入提示詞（中文應該也可以，助教習慣英文）＋Character Sheet → 生成角色卡 → 以它為參考圖，打「半身像」＋「空白背景」→ 再把半身像變成影片。聊天機器人的**待機畫面**用「animation」之類的提示詞做出循環影片。

### 結合 RAG、MD 文件與 AI Agent

- 大家多半做 AI 客服、AI 律師、AI 助教，少數做「很霸氣的 AI 律師」「傲嬌的 AI 客服」。
- 例：傲嬌律師聊天機器人解說**著作權法第三條**的五個重點——System Prompt 用前面的角色扮演優化，再用 **RAG** 把法條切好當系統文件，它就會真的按照法律調出重點。
- **為什麼角色扮演聊天機器人也需要 RAG／MD 文件？** 要大大降低互動過程雞同鴨講、**引用資料錯誤**的機率（企業做 AI 客服常這樣做）：
  - 設定是 2025 年遇到這個 AI 霸道總裁，沒有 RAG 時問「我們什麼時候認識？」它可能亂回 1998 年或 2000 年——把相遇時間寫進 RAG 或 MD 文件，回應就會對到。
  - 做 TRPG 類聊天機器人時，把**世界觀**寫成 RAG／MD 文件，避免突然冒出世界觀裡不存在的地點、人物，或從科幻世界變成奇幻世界。
  - 銀行最常被問的 10 個問題做成 MD，讓 AI 客服回答得更快、更準。
- **結合 AI Agent**：角色扮演聊天機器人也能調用工具。例：一個呆萌型可愛角色，熟悉地雷系、哥德風的視覺元素，並串接 **Google AI Studio 的 API** 生圖——不只聊天，而是有產出。網路上剛好有談哥德風視覺的論文、講地雷系的網站，可以用 Vibe Coding 請 AI 把 PDF 或網頁內容轉成 MD 檔當知識庫（或做 RAG）。

**粗略流程**

```text
使用者在介面輸入
    ↓
Python 意圖判定：要不要生圖？
    ├─ 不生圖 → 角色扮演，串 LLM → 呈現在前端
    └─ 生圖   → 角色扮演＋生圖：Python 取出生成內容中屬於生圖 prompt 的部分
                → 用 API 生成圖像 → 連同角色的話一起呈現在前端
```

### 示範：用 Antigravity 做出 GitHub Pages 聊天機器人

- 需求清單：能在 GitHub Pages 上執行的聊天機器人、串 Google AI Studio API、System Prompt（套用前面的優化）、影片素材（檔名寫在 prompt：待機影片循環播放；生完圖或完成工作後播「有點累」的影像）；把簡報那頁下載成 PDF 再轉 MD、地雷系網站轉 MD 當知識庫。再請 AI 根據這些寫出更好的 prompt，並告訴它之後要用 Antigravity 做。
- 步驟：建專案資料夾 → 新增 `assets` 資料夾放角色素材 → 用 Antigravity 開啟資料夾 → 貼上 prompt（重點是要它讀取 `assets` 裡的資料，例如待機狀態用 assets 裡的影片或 GIF）。
- 成果：產生可以直接放上 GitHub 變成 GitHub Pages 的聊天機器人，可分享給朋友；介面上可以填 API Key，邊聊天邊有角色影片（「雖然現在看起來有點生硬」）。也展示了之前部署好的同款（素材不同）；現場測試時它還在思考，沒等到回覆。

### 結語

- AI 聊天機器人的設計門檻已經很低（上次作業每個人人手一個），**做出獨特、有趣、「有作為」的 AI 角色互動才是王道**（助教自己作為「作家」的想法）。讓它扮演律師、客服也是一種角色扮演。
- 希望期末專案能做出跟之前很不一樣的聊天機器人。

## 名詞對照表

| 名詞 | 說明 |
|---|---|
| Embedding／特徵代表向量 | 輸入經神經網路某個隱藏層得到的向量，代表 AI 對輸入的理解 |
| Latent vector（潛向量）／latent tensor | 同上；圖像生成中常用 $z$ 表示，不一定是向量，也可能是矩陣或 tensor |
| 代理任務 | 容易找訓練資料、但需要理解輸入才能做到的任務，用來間接訓練出 embedding |
| Encoder（編碼器） | 輸入 → latent vector 的模型 |
| Decoder（解碼器）／生成器 | latent vector → 圖、照片、文字的模型 |
| Word2Vec（CBOW／Skip-Gram） | 用周圍字預測中間字／中間字預測周圍字，找出字的 embedding |
| Autoencoder（自編碼器） | 輸入和輸出一樣的模型，訓練後同時得到 encoder 和 decoder |
| VAE（變分自編碼器） | 讓 latent vector 每個元素都從常態分佈 $\mathcal{N}(\mu, \sigma^2)$ 抽樣的 Autoencoder |
| Deepfake（第一版） | 用 A 的 encoder 抓特徵、B 的 decoder 還原，把 A 換成 B |
| GAN（生成對抗網路） | 一度獨大的圖像生成模型，後來被 Diffusion 超越 |
| Diffusion Model（擴散模型） | 一步步加高斯雜訊（encoder，用算的），訓練 decoder 一步步去雜訊 |
| 高斯雜訊 $\varepsilon$ | 從常態分佈抽樣的雜訊 |
| $\alpha_t$、$\beta_t$、$\bar{\alpha}_t$ | 每一步加雜訊的比例參數；$\alpha_t = 1-\beta_t$，$\bar{\alpha}_t = \prod \alpha_i$ |
| 預測雜訊 $\varepsilon_\theta$ | Diffusion 的神經網路學的是「被加了多少雜訊」，而不是直接學原圖 |
| 排程器（Scheduler） | 用較少步數完成去雜訊的方法；開源模型通常會推薦排程器和步數 |
| LDM（Latent Diffusion Model） | 先用 VAE 把圖壓小，在 latent 空間做 Diffusion |
| Stable Diffusion | 最有名的 LDM：512×512 圖壓成 64×64 latent，CLIP＋U-Net＋VAE decoder |
| U-Net | 輸入輸出一樣大、形狀像 U 的 CNN；以前常做 segmentation，現在是 Diffusion 的雜訊預測器 |
| Segmentation（分割） | 把圖中物件框起來塗滿，標出每個像素屬於什麼 |
| CLIP | 用圖片＋圖說做對比學習訓練，讓文字 embedding 和圖像 embedding 接近 |
| 對比學習（Contrastive learning） | 同類拉近、不同類推遠的訓練方式 |
| Q、K、V | Transformer 的 query、key、value；文字給 K、V，隨機 latent 給 Q，把語意融進去 |
| Stop At／Weight | 控制 prompt 影響到哪一步為止／影響多強 |
| ComfyUI | 在自己電腦跑生圖、生影片模型的常用介面 |
| Character Sheet（角色卡） | 角色全身像＋三視圖，當參考圖維持角色一致性 |
| RPG Action Sheet／Sprite Sheet | 角色動作表，拆成影格做動畫（如 AI 桌寵） |
| Emoji Package | 同一角色多種表情的圖，可依 AI 回覆的情緒顯示 |
